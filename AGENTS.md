# AGENTS.md

## Commands

- `deno run dev` - Start the dev server
- `deno run build` - Build the app for production
- `deno run preview` - Preview the production build locally

## Docs

- Rsbuild: https://rsbuild.rs/llms.txt
- Rspack: https://rspack.rs/llms.txt
- Rstest: https://rstest.rs/llms.txt
- Rslint: https://rslint.rs/llms.txt

## Tools

### Rstest

- Run `deno run test` to run tests
- Run `deno run test:watch` to run tests in watch mode

### Rslint

- Run `deno run lint` to lint your code

### Prettier

- Run `deno run format` to format your code
